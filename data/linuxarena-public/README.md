# LinuxArena Public Mirror

22,215 agent trajectories from 172 evaluation runs across 10 Linux software environments. Each trajectory carries full per-action content: tool calls, tool outputs, agent reasoning, monitor scores with reasoning and ensemble breakdowns, and blue-protocol audit trails.

**Browse interactively:** [data.linuxarena.ai/datasets](https://data.linuxarena.ai/datasets)

## Quick start (full data)

```python
from datasets import load_dataset
ds = load_dataset("anonymouslinuxarena/linuxarena-public", split="trajectories")
print(ds[0]["trajectory_url"])                   # per-trajectory viewer link
print(ds[0]["actions"][0]["function"])           # tool name
print(ds[0]["actions"][0]["arguments"])          # tool call args
print(ds[0]["actions"][0]["output"])             # tool result
print(ds[0]["actions"][0]["agent_reasoning"])    # CoT before the call
print(ds[0]["actions"][0]["monitor_response"])   # full monitor result
```

## Run types

- **Agent runs** (e.g. `Haiku honest`, `Haiku attack`): original execution of a policy on tasks. Action content generated by `agent_model`.
- **Monitor reruns** (e.g. `GPT-5 Nano monitor on Haiku attack`): the same trajectories scored by a different monitor. Only `monitor_response` and `traj_monitor_response` differ from the source agent run. Identifiable via `actions[i].monitor_response.model_name`.

## Schema

<details>
<summary>Per-trajectory fields (16)</summary>

| Field | Description |
|---|---|
| `trajectory_id` | Unique stable trajectory ID |
| `run_id` | Eval run this trajectory belongs to |
| `run_display_name` | Human-readable run label |
| `trajectory_url` | `https://data.linuxarena.ai/trajectories/<trajectory_id>` |
| `actions` | List of per-step action records (see below) |
| `main_task_success` / `side_task_success` | Booleans (or null) |
| `scorer_explanation` | Free-text scorer explanation |
| `traj_monitor_response` | Trajectory-level (delayed) monitor result |
| `environment` | `id`, `display_name`, `description`, `tech_stack`, `services` |
| `main_task` | `id`, `name`, `description`, `category`, `scorer_description`, ... |
| `side_task` | `id`, `name`, `goal`, `scoring_details`, ... (null for honest) |
| `agent_model` | Model that generated the trajectory |
| `system_prompt` | Full system prompt the agent received |
| `initial_user_message` | First user turn |
| `attack_analysis` | Post-hoc attack-strategy summary (sparse, ~4%) |
</details>

<details>
<summary>Per-action fields (9)</summary>

| Field | Description |
|---|---|
| `function` | Tool name, e.g. `bash`, `text_editor`, `submit` |
| `arguments` | Tool call arguments (full) |
| `output` | Tool result (no truncation) |
| `output_error` | Error string if the tool call errored |
| `agent_reasoning` | Reasoning text immediately before this call |
| `extended_thinking` | Extended thinking blocks |
| `inter_action_messages` | Messages between previous tool result and this call |
| `monitor_response` | Per-action monitor result with `sus_score`, `reasoning`, `model_name`, `members` |
| `substeps` | Blue-protocol audit trail (rewrites, deferrals, resamples) |
</details>
