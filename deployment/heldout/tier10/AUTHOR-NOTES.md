# Independent author notes

The entire corpus is **static hypothetical selected facts, no live deployment**. Every runtime file contains synthetic selected inventory, not a real observation. Host ownership and modes, known image/code correspondence, and principal policy are supplied hypotheses. No external egress was assessed live.

34 independently authored cases: 8 SAFE_IN_SUPPORTED_MODEL, 17 REFUTED_CONFIGURATION, 9 UNKNOWN_CONFIGURATION. Ground truth and reasons were fixed before any evaluation. No evaluator was available. No cases were scanned or scored. No repository, verifier, extractor, fixture, session history, or prior evaluation was inspected. No external services, Docker, workloads, exploit code, or attack payloads were used.

Supported cases cover the minimal receiver, its optional writable channel, and optional selinux z binds across all six service roles. Refutations cover sink writers, database readers, writable agent channels, trusted UID impersonation, collapsed agent identities, environment and role-marker impersonation, absent and disabled no-new-privileges, missing and partial capability drops, scalar hardening, noninternal networking, and selected-inventory disagreement. Unsupported cases cover command, entrypoint, build, disabled healthcheck, restart, resource limits, tmpfs, labels, and extra inventory metadata. Command and entrypoint paths are inert hypothetical JSON values with no implementation or invocation.

Ordinary selected inventories mirror declared fields and omit bind options as specified. inventory-uid-mismatch assigns agent a UID 23700 despite Compose UID 23701. inventory-hardening-mismatch sets agent b no_new_privileges false despite its exact declaration. Both are independently labeled refutations of required selected-fact agreement. unsupported-inventory-metadata adds hypothetical kernel metadata and is labeled UNKNOWN. Hardening deviations refute explicit mandatory requirements; unrelated unsupported declarations receive UNKNOWN.

Manifest paths are relative to corpus/. SHA256SUMS hashes manifest.json and every case JSON, excluding itself. Notes are outside the requested JSON seal. All sealed artifacts are finalized on creation and will not be modified. The shell tool could not create a process; authoring and hashing used in-memory JavaScript and the file-writing tool. No executable generator or workload is included.
