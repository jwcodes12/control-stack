# Held-out, finite-history monitor calibration (F6 support)

Run `python3 tools/monitor_calibration.py --input /path/to/held-out.jsonl --output /new/report.json --alpha 0.05` after freezing a monitor/threshold and history-stratum policy. Each input line must contain only `id` (globally unique string), `history` (predeclared stratum string), `attack` (boolean) and `alarm` (boolean).

For each history, report the attack miss rate and benign false-positive rate. A one-sided Hoeffding upper bound for every rate uses `empirical_rate + sqrt(log((2 * H)/alpha)/(2*n))`, where `H` is the number of observed strata and `n` the corresponding count for the relevant truth class, clipped to 1. Applying the union bound across both rates and every observed stratum yields familywise coverage at least `1-alpha` **only if** the rows for each class and stratum are genuinely independent held-out samples of the deployment-analog conditional law, the strata and monitor were frozen before the data, ground truth is valid and data collection is not adaptively biased. In particular, this cannot be interpreted as robust coverage of every adaptive strategy, all histories or correlation between multiple agents. The finite data are not asserted to validate F6 premises for the real system.

Sparse strata (by default fewer than 30 attack samples **or** fewer than 30 benign samples) have `null` upper bounds and a report `status=insufficient_samples`. The CLI exits nonzero in this case, even though it writes a new audit receipt, preventing a successful CI process from laundering missing evidence. This `30` is a **reporting minimum**, not a sufficient sample size for tight bounds or honest usefulness. Every new history increases the simultaneous-comparison penalty; unseen histories are not covered at all. Output refuses overwrite. Do not edit frozen preregistrations or pretend existing Redwood monitor scores are predeclared iid data if they aren't.

The matching review-scoped Lean source `reviews/family-strengthening/Remaining.lean` proves that assuming a per-history missed weighted-mass bound, the sum over histories is bounded. It does not formally verify the Hoeffding derivation, sampling law, normality, monitor calibration implementation, or its data source. For real assurance, require independent fixed-sample collection, signed evaluation policy and full observational threat mapping.
