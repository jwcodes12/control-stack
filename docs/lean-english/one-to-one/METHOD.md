# Method and limits

Only `sol-input/part-g0.md` was used as English input. No English in the other copies, canary keys, or unpublished draft proofs were read. Current branch remains `eng/close-open-items`; no pushes, commits, branch changes, containers, packages, or proofledger edits were made.

The 26 semantic targets were written and SHA-frozen before opening the current original declaration files. Prior exposure to these deployment contracts during implementation is explicitly disclosed. **The Lean encodings were typed after that semantic freeze and original-source read. This does not meet the protocol's stricter requirement to save the Lean back-translation before reading the original.** These are formal statement-comparison results, not a fully compliant blind back-translation experiment. A first-exposure blind checker is still needed for that experimental claim.

Compare pointwise conclusions and predicate definitions, rather than using the fact that two closed universally quantified statements are already provable to manufacture an equivalence. Each ordinary equivalence file also type-checks an `original_contract` application against the original theorem, including its hypotheses. Literal weakened conclusions and equivalence on the hypothesis-restricted domain are distinguished. World-assumption narratives, attribution, and human semantic interpretation are not certified by a propositional proof.

The original gate failed because its hard-coded `import Mathlib` has no top-level `Mathlib.olean` in the offline cache. The local `leangate_imports.py` adds only the requested `PL_IMPORTS` header option; `leangate-imports.patch` records the complete change. `gate-security-check.json` checks identical banned-token patterns, statement patterns, permitted axioms, and six rejection controls. The original proofledger checkout is untouched. This local adapter has not been committed upstream as requested in the agent handoff; it is reviewable here under the user's single-clone constraint.

Every statement check, nonce-based claim axiom check, and separate witness axiom check is retained with SHA receipts. Gate witness `Accepted clean` is a minimal nondegenerate configuration witness; it alone is not a non-vacuity certificate for every protocol premise. Protocol non-vacuity is additionally supplied by the existing useful broker/SC26 examples and the recorded replay; those inputs are explicit model instances, never runtime correspondence proofs.

ProvenanceDraft proves state invariants for signer role, agent role, existing artifact, present role-authenticated review, and lease ownership. It does not preserve the identity of the first reviewer: reviews can be overwritten, and reviewer/approver roles need not be mutually exclusive in arbitrary Roles. It does not assert review content is harmless, full model/runtime correspondence, exact digest/destination of each published file, or any real-system guarantee.
